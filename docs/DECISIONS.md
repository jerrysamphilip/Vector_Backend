# Outreach 360 client decision sheet

Release 1.1.0 · prepared 2026-10-18, updated 2026-10-29 (DEC-01, 05, 11, 18 refreshed; DEC-24 … 27 added) · NTS Build Standard Addendum §4 ("Client decision sheet") and §5 item 16.

Every open decision is listed below with options, a recommendation, the behaviour the code has **today if nobody
decides** ("Default if not decided"), and whether it blocks go-live. Nothing in the list was decided silently
in code: each default is what the shipped code and manifests do now. Rows marked **Decided** record a choice
already made. They still need a client sign-off.

Decision ids are `DEC-nn`, which keeps them apart from the addendum rule ids (D-11 … D-14). The runbook
([OPERATIONS.md](OPERATIONS.md)) and the review responses ([REVIEW_RESPONSES.md](REVIEW_RESPONSES.md)) refer to
these ids. Owner is the role expected to decide. The client fills in **Sign-off** and **Date**.

## How to sign off

1. For each row, choose an option (or accept the recommendation) and write it into **Sign-off** with your name. Add the **Date**.
2. Rows marked Y must be signed before go-live. If a recommendation needs a code or manifest change, NTS schedules it and links the change here.
3. Moving a requirement out of the release (DEC-07) is also recorded in the Notes column of [REQUIREMENTS.md](REQUIREMENTS.md) and in `CHANGELOG.md`.
