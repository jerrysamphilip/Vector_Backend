# Review responses

Release 1.1.0 · 2026-10-18, rows re-checked against the code 2026-10-29 · NTS Build Standard Addendum §4 ("Review responses") and §5 item 12.

This page answers, item by item:

- **Part A**: the external code review (AMS code review comments: findings on PatientTrack, plus the
  architecture and SOLID review). Each one is mapped to the matching Outreach 360 (Vector) code.
- **Part B**: the addendum rules C-1 … C-9, T-1 … T-6, I-11 … I-17, D-11 … D-14, W-9 … W-13, P-1 … P-4.

Status values: **Fixed** (built, with a test) · **Fixed in part** (some of it built and tested, the rest stated) ·
**Decision** (open client decision in [DECISIONS.md](DECISIONS.md)) · **Trade-off** (deliberate, recorded in an
ADR) · **Open** (not done, no decision yet) · **N/A** (no matching code in Vector) · **In progress (next)** (work
is under way on this branch; the row will be updated when it lands).

Version: **1.1.0** means it is in this release; **next** means it is not finished yet. Every "Fixed" row names
the test that proves it. A CI gate listed under Test runs on every push (`.github/workflows/ci.yml`; gates are
described in [CI_GATES.md](CI_GATES.md)). Backend tests are under `tests/` (functional) and `tests/unit/` (unit);
frontend tests are in `Vector_Frontend/src/**.test.*`.
